# תורנויות אצל סבא וסבתא - לקוח React

לקוח מינימלי שמדגים את השרת. כדי להריץ אותו, השרת צריך לרוץ קודם בכתובת http://localhost:5080.

```
npm install
npm run dev
```

אחר כך פותחים את הדפדפן בכתובת http://localhost:5173

## המסכים

- **התחברות והרשמה:** ה-JWT נשמר בדפדפן ונשלח בכל בקשה ב-header `Authorization`.
- **לוח התורנויות:** רשימה עם pagination אמיתי מול השרת.
- **"אני מגיע/ה":** לקיחת תורנות. אם השרת מחזיר 409, מוצגת הודעה ברורה שהתורנות נתפסה.
- **"הדגמת תחרות":** שולח שתי בקשות באותו רגע על אותה תורנות. רק אחת מהן מתקבלת, והשנייה מקבלת 409.
- **התורנויות שלי:** רשימת השיבוצים הפעילים, עם אפשרות ביטול.
